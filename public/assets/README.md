# Local media system

The site includes small original generated WebP placeholders. They are local, stable, and do not use official game assets.

## Licensed hero video

Place the licensed video here:

- `public/media/hero/hero.mp4`
- `public/media/hero/hero.webm` (optional preferred format)

The site is poster-first, so it remains visually complete without either video. On mobile and when reduced motion is requested, it intentionally uses the local poster instead of requesting video.

## Replaceable images

Replace only with assets you have the rights to use:

- `public/media/hero/hero-poster.webp`
- `public/media/games/`
- `public/media/studio/`
- `public/media/projects/`
- `public/media/careers/`
- `public/media/news/`

Do not add copyrighted Activision, franchise, or studio media without permission.
